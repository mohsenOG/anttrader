# AntTrader

Experimental Langton's Ant trading signal research for Gold (XAU/USD) using Python.

AntTrader investigates whether the behavior of Langton's Ant, a cellular automaton,
can provide predictive information about Gold on the **1-hour timeframe**.
Profitability is unknown.

**Status:** Topic 1 foundation complete and verified. The pipeline and dashboard
display setup
status. Data loading, simulation, signal generation, and backtesting are not yet
implemented. Topics 2-5 require detailed approval.

## Planned capabilities and architecture

Historical XAU/USD candles -> market grid -> Langton's Ant -> numerical features
-> BUY/SELL/HOLD decoder -> backtest -> Streamlit visualization.

The pipeline will coordinate the research modules. The dashboard will show the ant,
signals, and backtest results. Historical datasets stay in `data/`; generated
outputs stay in `results/`. Both directories are ignored except for placeholders.
No market data, signals, or performance metrics are generated by this scaffold.

## Technologies

Python 3.13, NumPy, pandas, scikit-learn, Streamlit, Plotly, and PyYAML.
Local checks use pytest and Ruff. Dependencies are declared in `pyproject.toml`.

## Installation

Use Python 3.13. In PowerShell:

```powershell
git clone https://github.com/mohsenOG/anttrader.git
cd anttrader
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\Activate.ps1
```

Activation is optional. If PowerShell blocks it, use `.venv\Scripts\python.exe`
instead of `python`, and `.venv\Scripts\ruff.exe` instead of `ruff`.
No global execution-policy change is required.

## Local verification

With the virtual environment active:

```powershell
python -m pytest -q
ruff check .
```

## Run the scaffold

```powershell
python -m anttrader.pipeline
streamlit run app.py
```

The pipeline prints a placeholder message. The dashboard shows the project purpose
and setup status. Neither command runs research or trading logic yet.
Without activation, use `.venv\Scripts\python.exe -m anttrader.pipeline` and
`.venv\Scripts\python.exe -m streamlit run app.py`.

## Configuration and planning

`config.yaml` records XAU/USD, 1H, and historical research mode. It also records
provisional defaults: one ant, 256 returns, a 16 x 16 grid, 2,048 steps, toroidal
boundaries, logistic regression, and a four-bar prediction horizon. These values
are not optimized and do not yet drive behavior.

Read [SPEC.md](SPEC.md) for scope and open decisions, [TASKS.md](TASKS.md) for
progress, and [AGENTS.md](AGENTS.md) for persistent Codex instructions.
Topic 2 will specify market data and grid encoding.
